# Expense & Budget Visualizer

Halo, saya adalah peserta Coding Camp yang sedang mempelajari dasar-dasar software engineering melalui pembuatan project web sederhana. Repository ini berisi project Expense & Budget Visualizer, yaitu aplikasi web mobile-friendly untuk membantu pengguna mencatat pengeluaran harian, melihat total saldo, mengelola transaksi, dan memvisualisasikan pengeluaran berdasarkan kategori.

Project ini dibuat menggunakan HTML, CSS, dan Vanilla JavaScript tanpa framework tambahan. Data disimpan menggunakan Local Storage API sehingga seluruh data tersimpan langsung di browser pengguna.

Fitur utama dalam project ini meliputi:

* Menambahkan transaksi berdasarkan nama item, jumlah, dan kategori
* Menampilkan daftar transaksi
* Menghapus transaksi
* Menghitung total balance secara otomatis
* Visualisasi pengeluaran menggunakan pie chart
* Tampilan responsive dan mudah digunakan

Melalui project ini, saya belajar mengenai struktur dasar pengembangan web, manipulasi DOM, validasi form, pengelolaan data client-side, serta deployment menggunakan GitHub Pages.
